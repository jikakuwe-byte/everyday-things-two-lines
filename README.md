Two lines explaining a toaster to a 10-year-old. Line 1: A toaster is like a tiny sunbathing dragon: bread goes in pale, lies on a hot metal beach, and comes out golden and crisp. Line 2: The analogy works because both use heat to turn pale things brown, but it leaves out that dragons have no pop-up timer or crumb tray. Running the program prints the two lines, and nothing else.

## Run it

```sh
node main.ts
```
